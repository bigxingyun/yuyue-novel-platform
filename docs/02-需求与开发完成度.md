## 2. 已实现需求清单

### 2.1 用户与认证

| 编号 | 需求 | 后端 | 前端 |
|------|------|------|------|
| U01 | 注册码校验（一次性、可过期） | `auth_service.verify_registration_key` | `RegisterView` |
| U02 | 注册（昵称 2–20 字唯一、密码 ≥6 位） | `auth_service.register`（原子消费注册码） | `RegisterView` |
| U03 | 登录（昵称或 ID + 密码） | `auth_service.login`（封禁拒绝） | `LoginView` |
| U04 | Token 刷新（access 2h / refresh 7d） | `auth_service.refresh` | `http.ts` 拦截器单飞刷新 |
| U05 | 找回密码（找回密钥一次性） | `auth_service.recover_password` | `RecoverView` |
| U06 | 修改资料（部分更新，昵称未改不校验） | `profile_service.update_profile` | `EditProfileView` |
| U07 | 修改密码（校验旧密码） | `profile_service.change_password` | `ChangePasswordView` |
| U08 | 登出 | `POST /auth/logout`（无状态） | `userStore.logout` |

## 3. 部分实现与已知限制

| 项 | 现状 | 影响 |
|----|------|------|
| 广场字数区间筛选 | 需求分析 §7.3 标注「尚未实现」 | 无字数筛选 UI |
| 性能指标 | P95 < 300ms / 章节切换 < 500ms 为目标，未做压力测试 | 见需求分析 §14 |
| 自动化测试覆盖 | 后端 pytest 覆盖核心业务；前端仅 1 个 vitest 单测（`parseChapterBlocks.test.ts`） | 见 [10-测试.md](./10-测试.md) |
| 评论回复层级 | 仅支持一级回复（`parent_id` 指向顶级） | 产品决策，非缺陷 |
| 头像 | 上传功能未开放（仅默认 DiceBear / 外链 URL） | `PATCH /users/me` 可传任意 URL；`/upload/image` 面向正文插图 |
