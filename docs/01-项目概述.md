## 1. 产品定位

「欲阅」是以**短篇小说**为核心的多用户在线阅读平台，侧重：

- **沉浸式阅读**：全屏阅读页、字号/主题/翻页模式可调、进度续读；
- **细粒度互动**：段评 / 章评 / 书评三级评论，作者可置顶；
- **轻量创作**：作者发布作品与章节，正文支持插入图片块；
- **可控运营**：注册码准入、作者申请审核、管理后台治理。

设计原则（详见需求分析 §1.3）：

| 原则 | 说明 |
|------|------|
| 导航页为公共入口 | 首次访问 `/` 完成品牌展示与登录引导 |
| 权限双重校验 | 前端路由守卫 + 后端 `deps` 鉴权 |
| 阅读体验优先 | 阅读页全屏，顶栏默认隐藏，二级面板收纳目录/进度/设置 |
| 凭证制注册 | 注册码由管理员生成、一次性使用 |
| 续读路径短 | 书架/历史点击封面直达阅读页并恢复进度 |

## 3. 技术栈

| 层级 | 选型 | 版本要点 |
|------|------|----------|
| 前端 | Vue 3 + TypeScript + Vite | Composition API；`@phosphor-icons/vue` 图标 |
| 路由 / 状态 | Vue Router 4 + Pinia | 懒加载、导航守卫 |
| HTTP | Axios | 拦截器做字段转换、Token、统一错误 |
| 后端 | Python FastAPI | OpenAPI `/docs` |
| ORM | SQLAlchemy 2.x | 模型即表结构；非 Alembic，使用轻量增量补丁 |
| 数据库 | SQLite | 开发与生产默认；路径由 `DATABASE_URL` 配置 |
| 认证 | JWT (HS256) | Access 2h，Refresh 7d |
| 密码 | bcrypt | `passlib` + `bcrypt<4.1.0` |
| 静态文件 | 本地 `uploads/` | 头像、封面、章节插图；生产由后端同端口托管 |

## 4. 角色体系

```
guest ──注册──► user ──申请+审核──► author
                     admin ◄──指派── superadmin
```

| 角色 | 标识 | 说明 |
|------|------|------|
| 访客 | `guest` | 未登录；可浏览广场（后端读接口公开） |
| 普通用户 | `user` | 注册码注册；阅读、评论、书架、签到 |
| 作者 | `author` | 申请审核通过；管理作品/章节、置顶评论 |
| 管理员 | `admin` | 后台治理（超管指派） |
| 超级用户 | `superadmin` | 种子账号；指派/撤销管理员 |

账号状态：`active`（正常）/ `banned`（封禁）。

## 5. 名词速查

| 术语 | 定义 |
|------|------|
| 注册码 | 管理员生成的单次注册凭证（`registration_keys`） |
| 找回密钥 | 指定账号的单次密码重置凭证（`recovery_keys`） |
| offset | 章内阅读位置，0–1 表示滚动比例 |
| 正文块 | 章节 `content` 按 `\n\n` 切分得到的文本段 / 图片块 |
| 图片块 marker | 整行 `[img:/uploads/...]`，存储为 `/uploads/` 相对路径 |
| CommentDock | 书主页书评独立滚动容器 |
| 阅读头衔 | 经验累计映射的展示等级（Lv.1–10），与权限 `role` 正交 |
| ApiResponse | 统一响应 `{ code, message, data }` |
| PageResult | 分页 data：`{ items, total, page, page_size }` |
