## 文档分工原则

| 文档 | 职责 | 禁止 |
|------|------|------|
| `欲阅需求分析.md` | 做什么：功能、页面、接口、表结构 | 重复实现细节 |
| `docs/*.md`（本文档族） | 怎么做、怎么跑、做到哪 | 与需求分析大段重复（用链接引用） |
| `README.md` | 项目入口、快速启动 | 大段业务描述 |
| `backend/README.md` / `frontend/README.md` | 各端开发说明 | — |

> 同一件事单点维护 + 链接引用，禁止多文档复制粘贴（见 CONVENTIONS §1.3）。
